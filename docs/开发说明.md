# 开发说明

## 运行链路

```
WebView
  └─ http://127.0.0.1:17890/     ← LocalServer 从 assets/www 读文件
       ├─ index.html / style.css / app.js / db.js
       ├─ POST /api/analyze       → https://api.deepseek.com/chat/completions
       ├─ GET  /api/models        → https://api.deepseek.com/models
       └─ POST /api/export        → 写入系统下载目录
```

`MainActivity` 启 `LocalServer`，然后加载本地地址。页面里的 `fetch` 请求 `/api/*`，由 `LocalServer` 用 `HttpURLConnection` 转发，所以浏览器侧没有跨域问题。

## 数据模型

`localStorage.profile`

```json
{ "height": 175, "weight": 65, "age": 22, "sex": "male", "activity": "sedentary", "goal": "cut", "apiKey": "" }
```

`meals` 表：自增主键 `id`，索引 `date`。

```json
{ "date": "2026-11-20", "name": "米饭", "grams": 200, "calories": 232, "protein": 4.8, "fat": 0.6, "carbs": 51.8, "mealType": "lunch", "timestamp": 1763600000000 }
```

`weights` 表：主键 `date`。

```json
{ "date": "2026-11-20", "weight": 64.2, "bodyFat": null }
```

## 计算规则

```
BMI  = 体重 / 身高²
BMR  = 10×体重 + 6.25×身高 - 5×年龄 + (男 5 / 女 -161)
TDEE = BMR × 活动系数        久坐 1.2  轻度 1.375  中度 1.55  高度 1.725
目标热量 = TDEE - 每日缺口        减脂，缺口可调，默认 350
         = TDEE                    维持
         = TDEE × 1.10             增肌
        如果低于 BMR×1.1，取 BMR×1.1，标记 clamped
蛋白质 = 体重 × 蛋白质系数          默认减脂 1.8，其他 1.6，可调
脂肪   = 目标热量 × 脂肪占比 / 9    默认 22%，可调
碳水   = (目标热量 - 蛋白质×4 - 脂肪×9) / 4
```

内部保留两位小数，界面取整。

## 原生层

`MainActivity`：

- 状态栏白色、深色图标
- WebView 开 JS、DOM storage、数据库，关 file access
- UA 追加 `CalorieApp`，前端据此切换接口地址
- `WebChromeClient.onPermissionRequest` 授予摄像头，未授权时先申请运行时权限再授予
- `onShowFileChooser` 支持相册选图和导入文件
- 返回键先调 `window.__onBack()`，返回 false 时退出

`LocalServer`：

- 固定端口 17890，绑定 127.0.0.1，启动失败重试 20 次
- 静态文件按扩展名给 MIME，找不到路径回退 index.html
- `/api/analyze`、`/api/models` 转发到 DeepSeek，透传状态码与响应体
- `/api/export` 用 MediaStore 写入下载目录（Android 10 以上），低版本直接写文件
- 拒绝路径里带 `..` 的请求

端口不能改成随机：origin 含端口，端口一变，localStorage 和 IndexedDB 就换了一套。

## 迭代流程

1. 改 `www/` 下的文件，样式在 `style.css`，交互在 `app.js`
2. `bash build.sh`
3. 装 `dist/卡路里小助手.apk` 实测
4. 验证通过再提交，提交信息写清楚改了什么、为什么
5. 攒够阶段性成果再发版，平时只递增 `versionCode`

## 版本号

`android/AndroidManifest.xml` 里两个字段：

- `android:versionCode`：整数，每次构建都加一
- `android:versionName`：正式发行时才升级

## 签名

签名文件 `keys/release.jks`，口令 `keys/storepass`，都不入库。丢失后无法用新包覆盖安装，只能卸载重装。换机器前先把整个 `keys/` 备份走。

## 接口

识别请求：

```json
{
  "model": "deepseek-flash",
  "temperature": 0.1,
  "messages": [{
    "role": "user",
    "content": [
      { "type": "text", "text": "分析这张食物照片，只返回 JSON……" },
      { "type": "image_url", "image_url": { "url": "data:image/jpeg;base64,...", "detail": "low" } }
    ]
  }]
}
```

图片在 `captureFrame` 里压到宽 1280、JPEG 质量 0.72。返回文本先用 `/\{[\s\S]*\}/` 取 JSON 片段，解析失败把原文放进抽屉让用户手填。

模型名在 `www/app.js` 顶部 `MODEL` 常量，换模型只改这一处。
