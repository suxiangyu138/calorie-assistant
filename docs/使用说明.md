# 使用说明

## 安装

1. 把 `卡路里小助手.apk` 传到手机（iQOO 可直接用文件管理器打开下载目录里的安装包）。
2. 首次安装需要允许「安装未知来源应用」，按系统提示打开即可。
3. 安装完成，桌面图标是蓝色短发女孩，名称「卡路里小助手」。

系统要求 Android 8.0 及以上。

## 首次设置

打开后先填身体信息：身高、体重、年龄、性别、活动水平、目标。点「开始记录」进入首页。

设置页会同步显示算出来的 BMI、基础代谢、每日总消耗、目标热量、蛋白质、脂肪、碳水目标。减脂时目标热量等于每日总消耗减去你选的缺口，如果低于基础代谢的 1.1 倍，会按下限计算并提示实际缺口。

## 日常使用

首页：

- 中间环形是今日已摄入热量与目标的比例，环下写目标与还能吃多少
- 三条细条分别是蛋白质、脂肪、碳水，右侧是「已摄入 / 目标」
- 下面是今日记录，点某一条可以改，点右侧叉号删除
- 顶栏左右箭头逐日切换，点中间的日期会弹出月历，可以直接跳到某一天
- 日历里可以翻月份，未到的日期点不了，底部「回到今天」一键回今天
- 右下加号进入拍照页

拍照页：

- 对准食物，点中间快门
- 左下「相册」可以从相册选图识别
- 右下「手动」直接手填
- 识别完成后从底部升起确认抽屉，上方取景画面仍然可见

确认抽屉里可以改名称、克数、热量，改克数时热量与营养素按比例重算，也可以直接改热量。可以删条目、加条目、选餐次。点保存才写进数据库，取消什么都不留。

如果模型返回的内容不是 JSON，抽屉里会显示原始返回，手动补即可。

## 记体重

统计页右上「记体重」，填体重，体脂率可以空着。同一天记两次会覆盖前一条。

## 统计

- 近七天热量柱状图，虚线是每日目标
- 近三十天体重折线
- 本周日均摄入、日均蛋白质、体重变化

数据不够时会显示一句提示，不会有空白图表。

## 设置

入口在统计页右上角「设置」。

- 身体信息：身高、体重、年龄、性别、活动水平、目标，改完立即重算
- 摄入参数：每日热量缺口、蛋白质系数、脂肪占比，三项都可以换成自定义值
- 计算结果：只读，是算出来的指标，包含预计每日缺口，触及安全下限或缺口过大时会有一行提示
- API 配置：填 DeepSeek 的 API Key，点校验会发一次请求确认可用
- 数据管理：导出、导入、清空

## API Key

设置页第三组填 DeepSeek 的 API Key，点校验会发一次请求确认可用。Key 存在本机，拍照识别会用到。

没填 Key 时拍照可以正常拍，识别会跳过，直接进手动录入抽屉。

## 备份与恢复

- 导出：设置页第四组「导出数据」，JSON 文件写到系统下载目录，文件名带日期
- 导入：同一组「导入数据」，选一个之前导出的文件，确认后覆盖当前全部记录
- 清空：会二次确认，清空后无法恢复，先导出

导出的文件包含身体信息和全部记录，不包含 API Key。

## 常见问题

打不开相机：首次使用会弹权限申请，选允许。如果之前拒绝过，去系统设置里给「卡路里小助手」开相机权限。

识别失败：先确认 API Key 已填且校验通过，再确认网络可用。Key 或模型不可用时，抽屉会显示接口返回的原始内容。

数据不见了：卸载重装会清空全部本地数据。换机或重装前先导出。

导入报错：只认本应用导出的 JSON，文件里的 `app` 字段必须是 `calorieApp`。
